    <h2>📌 Project Overview</h2>

    <p>
      This project aims to streamline and optimize various aspects of AtliQ Hardware’s business,
      including Finance, Sales, Supply Chain, Executive Management, and Marketing.
      The dashboard enables stakeholders to make data-driven decisions through interactive visualizations,
      KPI tracking, forecasting, and business performance analysis.
    </p>

      <strong>Main Goal:</strong> Improve business efficiency, profitability, forecasting accuracy,
